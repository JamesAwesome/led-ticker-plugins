# led-ticker-flight

Planes-overhead ADS-B flight tracker widget for [led-ticker](https://docs.ledticker.dev) — shows nearby aircraft (callsign, altitude, speed, track, distance, climb/descend cue) pulled from a local ADS-B receiver, rendered as a smallsign crawl, a bigsign hi-res hero, or a longboi dashboard row.

Design: see `design/README.md` — the normative visual spec.
