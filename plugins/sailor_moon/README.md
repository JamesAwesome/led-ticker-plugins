# led-ticker-sailor-moon

Sailor Moon sprite-trail transitions for [led-ticker](https://github.com/JamesAwesome/led-ticker) — `sailor_moon.forward` / `sailor_moon.reverse` / `sailor_moon.alternating`.

> **Unofficial fan homage.** "Sailor Moon" is the creation of Naoko Takeuchi (Toei Animation / Kodansha) (no bundled artwork — the effect is drawn procedurally). Non-commercial homage, no affiliation/endorsement. See the repo [NOTICE](https://github.com/JamesAwesome/led-ticker-plugins/blob/main/NOTICE.md).

Part of the [led-ticker-plugins](https://github.com/JamesAwesome/led-ticker-plugins) monorepo. Install:

```bash
pip install "git+https://github.com/JamesAwesome/led-ticker-plugins.git@sailor_moon-v0.1.0#subdirectory=plugins/sailor_moon"
```

Split out of the former `led-ticker-arcade` plugin (was `arcade.sailor_moon*`).
