# led-ticker-nyancat

Nyan Cat sprite-trail transitions for [led-ticker](https://github.com/JamesAwesome/led-ticker) — `nyancat.forward` / `nyancat.reverse` / `nyancat.alternating`. Ships a bundled hi-res sprite (`sprites/nyancat.webp`).

Part of the [led-ticker-plugins](https://github.com/JamesAwesome/led-ticker-plugins) monorepo. Install:

```bash
pip install "git+https://github.com/JamesAwesome/led-ticker-plugins.git@nyancat-v0.1.0#subdirectory=plugins/nyancat"
```

Split out of the former `led-ticker-arcade` plugin (was `arcade.nyancat*`).
