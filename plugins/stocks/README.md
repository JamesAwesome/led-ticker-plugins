# led-ticker-stocks

A stock / equities ticker **plugin** for [led-ticker](https://github.com/JamesAwesome/led-ticker), backed by the [Finnhub](https://finnhub.io/) API. It contributes a `stocks.ticker` **Container widget** that cycles one scrolling price line per configured symbol.

This package is under active development — see the [led-ticker-plugins](https://github.com/JamesAwesome/led-ticker-plugins) monorepo for status.
