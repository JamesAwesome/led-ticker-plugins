# led-ticker-pokeball

Pokeball/Pikachu sprite-trail transitions for [led-ticker](https://github.com/JamesAwesome/led-ticker) — `pokeball.forward` / `pokeball.reverse` / `pokeball.alternating` — plus the `:pokeball.ball:` emoji (lo-res 8×8 + hi-res 32×32). Ships three bundled sprites (`sprites/pokeball.gif`, `sprites/pokeball-pikachu.gif`, `sprites/pikachu-run-transparent.gif`).

Non-commercial homage, no affiliation/endorsement. See the repo [NOTICE](https://github.com/JamesAwesome/led-ticker-plugins/blob/main/NOTICE.md).

Part of the [led-ticker-plugins](https://github.com/JamesAwesome/led-ticker-plugins) monorepo. Install:

```bash
pip install "git+https://github.com/JamesAwesome/led-ticker-plugins.git@pokeball-v0.1.0#subdirectory=plugins/pokeball"
```

Split out of the former `led-ticker-arcade` plugin (was `arcade.pokeball*` + `:arcade.pokeball:`).
